# AATG Experiments: Full Reproduction Guide

This document describes how to reproduce Experiment 1 and Experiment 2 from the
canonical data under `experiment/Data`.

Run all commands from the `experiment/` directory unless noted otherwise.

The commands below use Bash/Git Bash line continuations (`\`). In PowerShell,
run each command on one line or replace `\` with a backtick.

## File Inventory

Core files for data preparation:

```text
pdf_to_markdown.py            # Optional PDF -> Markdown conversion entry point
ptit_pdf_extractor.py         # Layout-aware PTIT PDF extractor used by pdf_to_markdown.py

split_chapters.py             # Splits full.md into chapters/chXX.md
```

```text

exp1_plot.py                  # Produces Experiment 1 figures and table
```

Core files for Experiment 2:

```text

exp2_judge_nvidia.py          # Runs NVIDIA-hosted LLM judges
exp2_aggregate.py             # Rebuilds group scores/stats from one judge textbook CSV
```

## Environment

Requirements:

- Python 3.11 or newer.
- An OpenAI API key for Experiment 1 embeddings and the OpenAI o3 judge.
- An NVIDIA NIM API key for the four NVIDIA-hosted judges in Experiment 2.

Install dependencies:

```bash
python -m pip install -r requirements-experiment.txt
```

API keys are not stored in the repository. For API commands, either pass keys
with `--openai-key` / `--nvidia-key` or set:

```bash
export OPENAI_API_KEY="YOUR_OPENAI_API_KEY"
export NVIDIA_API_KEY="YOUR_NVIDIA_API_KEY"
```

Command-line keys may be saved in shell history. Environment variables are
usually preferable for shared machines.

## Dataset Layout

The canonical input data uses three sources and six topics:

```text
experiment/
├── Data/
│   ├── AATG/
│   ├── DirectChat/
│   └── PTIT/
└── results/
```

Topics:

```text
antoanhedieuhanh
laptrinhhuongdoituong
ngonngulaptrinhcpp
ngonngulaptrinhjava
nhapmoncnpm
nhapmonttnt
```

Each source must contain one `full.md` per topic. Derived files such as
`outline.json`, `chapters/`, and `core_chapters.json` can be regenerated by the
preparation steps below.

If starting from PTIT PDFs instead of existing Markdown, use:

```bash
python pdf_to_markdown.py --folder Data/PTIT --out Data/PTIT --promote
```

This step is optional when the canonical `full.md` files already exist.

## Phase 0: Prepare and Validate Data

### 0.1 Extract Outlines

```bash
python extract_outline.py --root Data
```

Expected progress:

- Each textbook folder receives `outline.txt`.
- Each textbook folder receives `outline.json`.

### 0.2 Split Textbooks into Chapters

```bash
python split_chapters.py --root Data
```

Expected progress:

- Each textbook folder receives `chapters/chXX.md`.
- The splitter reads canonical `full.md` files only.

### 0.3 Select Core Chapters

```bash
python select_core_chapters.py --root Data/PTIT
python select_core_chapters.py --root Data/AATG
python select_core_chapters.py --root Data/DirectChat
```

Expected progress:

- Each of the 18 textbook folders receives `core_chapters.json`.
- The experiment dataset contains 18 textbooks x 5 chapters = 90 chapters.

### 0.4 Preflight Checks

Experiment 1:

```bash
python exp1_sdiv.py --preflight-only
```

Expected result:

```text
18 books, 90 chapters
```

Experiment 2:

```bash
python exp2_judge_openai.py --preflight-only
python exp2_judge_nvidia.py --judge nemotron49b --preflight-only
python exp2_judge_nvidia.py --judge mistral_nem --preflight-only
python exp2_judge_nvidia.py --judge llama70b --preflight-only
python exp2_judge_nvidia.py --judge qwen80b --preflight-only
```

Expected result:

- All five preflight commands report 18 books and 90 chapters.
- All five commands report the same dataset fingerprint.
- The scripts reject prompts that exceed `--max-input-tokens`; chapter text is
  not silently truncated.

Optional NVIDIA smoke test:

```bash
python test_nvidia_models.py \
  --api-key "YOUR_NVIDIA_API_KEY" \
  --output results/exp2_nvidia_model_check.json
```

This only checks model availability. It is not required for the benchmark
outputs.

## Experiment 1: Semantic Diversity

### 1.1 Compute Scores

```bash
python exp1_sdiv.py \
  --openai-key "YOUR_OPENAI_API_KEY" \
  --output results/exp1
```

Expected progress:

- The first run embeds 90 chapters with `text-embedding-3-small`.
- Later runs reuse `embedding_cache.json` when chapter text and model match.
- The compute step evaluates 18 textbooks x 10 chapter pairs = 180 pair rows.

Useful options:

```text
--no-cache          Recompute all embeddings
--no-stopwords      Do not remove Vietnamese stop words before ROUGE-L
--phase embed       Build only the embedding cache
--phase compute     Compute pairwise scores from existing embeddings
--phase aggregate   Aggregate from existing pairwise scores
--phase stats       Recompute statistics from textbook scores
```

Canonical outputs:

```text
results/exp1/
├── embedding_cache.json
├── exp1_pairwise_raw.csv        # 180 rows
├── exp1_textbook_scores.csv     # 18 rows
├── exp1_group_scores.csv        # 3 rows
└── exp1_stats.json
```

### 1.2 Plot Figures

```bash
python exp1_plot.py \
  --input results/exp1 \
  --output results/exp1/figures \
  --dpi 300
```

Canonical figure/table outputs:

```text
results/exp1/figures/
```

## Experiment 2: Pedagogical Quality Evaluation

Experiment 2 uses five judges:

```text
o3           OpenAI o3
nemotron49b  nvidia/llama-3.3-nemotron-super-49b-v1
mistral_nem  mistralai/mistral-nemotron
llama70b     meta/llama-3.3-70b-instruct
qwen80b      qwen/qwen3-next-80b-a3b-instruct
```

Each judge evaluates:

```text
90 chapters x 3 runs = 270 chapter-score rows
```

### 2.1 Run the OpenAI o3 Judge

```bash
python exp2_judge_openai.py \
  --runs 3 \
  --workers 2 \
  --sleep 5 \
  --output results/exp2_o3 \
  --openai-key "YOUR_OPENAI_API_KEY"
```

Resume after interruption:

```bash
python exp2_judge_openai.py \
  --runs 3 \
  --workers 2 \
  --sleep 5 \
  --output results/exp2_o3 \
  --openai-key "YOUR_OPENAI_API_KEY" \
  --resume
```

If the OpenAI account has a low TPM limit, add:

```text
--tpm-limit NUMBER
```

### 2.2 Run the Four NVIDIA Judges

Run these sequentially or in separate terminals. If HTTP 429 errors occur,
reduce `--workers` to 1 and increase `--sleep`.

```bash
python exp2_judge_nvidia.py \
  --judge nemotron49b \
  --runs 3 \
  --workers 2 \
  --sleep 3 \
  --output results/exp2_nemotron49b \
  --nvidia-key "YOUR_NVIDIA_API_KEY"
```

```bash
python exp2_judge_nvidia.py \
  --judge mistral_nem \
  --runs 3 \
  --workers 2 \
  --sleep 8 \
  --output results/exp2_mistral_nem \
  --nvidia-key "YOUR_NVIDIA_API_KEY"
```

```bash
python exp2_judge_nvidia.py \
  --judge llama70b \
  --runs 3 \
  --workers 2 \
  --sleep 3 \
  --output results/exp2_llama70b \
  --nvidia-key "YOUR_NVIDIA_API_KEY"
```

```bash
python exp2_judge_nvidia.py \
  --judge qwen80b \
  --runs 3 \
  --workers 2 \
  --sleep 5 \
  --output results/exp2_qwen80b \
  --nvidia-key "YOUR_NVIDIA_API_KEY"
```

Resume a NVIDIA judge by running the same command with `--resume`.

Resume protection checks:

- judge name
- model name
- dataset fingerprint
- chapter hash
- output folder consistency

Canonical outputs for each completed judge:

```text
results/exp2_<judge>/
├── exp2_chapter_scores.csv       # 270 rows
├── exp2_textbook_scores.csv      # 18 rows
├── exp2_group_scores.csv         # 3 rows
├── exp2_stats.json
├── dataset_manifest.json
└── coverage_report.json          # complete = true
```

The OpenAI o3 folder also writes:

```text
exp2_cost_report.txt
```

Rebuild group scores and statistics from a judge textbook file:

```bash
python exp2_aggregate.py \
  --input results/exp2_nemotron49b/exp2_textbook_scores.csv
```

### 2.3 Build the Five-Judge Ensemble

```bash
python exp2_ensemble.py \
  --o3 results/exp2_o3 \
  --nemotron49b results/exp2_nemotron49b \
  --mistral-nem results/exp2_mistral_nem \
  --qwen80b results/exp2_qwen80b \
  --llama70b results/exp2_llama70b \
  --output results/exp2_ensemble
```

The ensemble step rejects incomplete judge folders, incomplete coverage, or
inconsistent dataset fingerprints.

Canonical ensemble outputs:

```text
results/exp2_ensemble/
├── exp2_ensemble_textbook_scores.csv     # 18 rows
├── exp2_ensemble_group_scores.csv        # 3 rows
├── exp2_ensemble_stats.json
└── exp2_ensemble_judge_summary.csv       # 15 rows: 5 judges x 3 sources
```

### 2.4 Plot Figures

```bash
python exp2_plot.py \
  --input results/exp2_ensemble \
  --output results/exp2_ensemble/figures \
  --dpi 300
```

Canonical figure/table outputs:

```text
results/exp2_ensemble/figures/
```
